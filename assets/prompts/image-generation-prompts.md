# Image Generation Prompts

These prompts produced the raster assets in `assets/images/` and `assets/icons/` using Codex's built-in image generation tool.

Privacy rules for every prompt:

- No real customer names, job names, addresses, phone numbers, transcripts, or local paths.
- No Apple logo, MacWhisper logo, or exact third-party branding.
- No readable words unless a future asset intentionally needs controlled text.
- Abstract UI lines are allowed; real screenshots are not.

## Hero Image

Output:

- `assets/images/hero-macwhisper-notes-transcription.png`
- `assets/images/hero-macwhisper-notes-transcription.webp`

Prompt:

```text
Use case: productivity-visual
Asset type: GitHub README hero image, 16:9, target 1792x1024 or 1600x900 raster
Primary request: Premium macOS automation product hero image for a private repo that automates call-recording transcription.
Scene/backdrop: deep charcoal and dark navy studio background with subtle glassmorphism, soft warm amber and teal accents, elegant realistic desktop UI mockup vibes.
Subject: a clean abstract workflow: a generic notes window with an audio waveform card on the left, a transcription engine/terminal panel in the center, a job folder with a plaintext transcript document on the right, and a final notes text pane showing paragraph-like lines. Use generic UI shapes only.
Composition: cinematic wide banner, polished Apple-like desktop aesthetic, layered glass panels, crisp focus, subtle depth, professional SaaS/tooling feel.
Text policy: no readable words, no brand names, no logos, no Apple logo, no MacWhisper logo, no customer names, no addresses, no local paths. Only abstract UI lines and icons.
Style: high-end realistic 3D/UI mockup, refined lighting, premium product visual, not cartoonish, not SVG/vector art, no watermark.
```
