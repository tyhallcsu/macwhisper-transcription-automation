# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be respectful, assume good intent, and keep discussion focused on the project. Harassment, personal attacks, and discriminatory language are not welcome.

## Reporting

If you experience or witness behavior that violates this code, report it through one of:

- **GitHub** — open a private vulnerability report on this repo (Security tab → Report a vulnerability) and tag it as a conduct issue, or
- **Direct message** the repo maintainer via their GitHub profile.

Reports are handled confidentially. Retaliation against reporters is itself a violation.

## Enforcement

The maintainer may, at their sole discretion: warn, temporarily limit interaction, or permanently ban contributors who violate this code.
